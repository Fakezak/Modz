# FF No Recoil and Auto Headshot

This is a simple Python tool for automating Free Fire gameplay with no recoil and auto headshot features. The tool uses color tracking to find enemies and simulate mouse movement for automatic headshots.

## Features:
- No recoil by adjusting the mouse position.
- Auto headshot by tracking enemy color (red).
- Simple implementation using Python with `pyautogui`, `opencv-python`, and `numpy`.

## Requirements:
- Python 3.x
- `pyautogui` for controlling the mouse.
- `opencv-python` for screen capture and color detection.
- `numpy` for array manipulation.

## Installation:
1. Clone the repository:
   ```bash
   git clone https://github.com/Fakezak/Modz.git
   ```

2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the script:
   ```bash
   python main.py
   ```
